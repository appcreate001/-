Свадебное приглашение Shoxrux & Marjona

index.html              — страница (использует style.css, script.js, папку images)
style.css, script.js    — стили и скрипты (дата отсчёта: const T в script.js)
images/                 — цветы и дворец (вырезаны из оригинала)
source/poster-original.jpg — исходный постер
index-single-file.html  — всё в одном файле, можно открыть двойным кликом или отправить как есть

Загрузите папку на любой хостинг (Netlify, GitHub Pages, свой сервер) — index.html откроется как главная.
